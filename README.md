# Labb1
Program som ber användaren att mata in en sträng. Försöker sedan leta efter substrängar som startar och slutar på samma tal, med inga bokstäver emellan. 
Kommer sedan skirva ut den inmatade strängen för de antal gånger som accetabla substrängar hittas. samt färga substrängarna i rött.
Skriver också ut det totala värdet av alla substrängar.
